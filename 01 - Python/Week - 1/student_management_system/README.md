# Student Management System

A simple command-line Student Management System built with Python as the final project for Week 1 of my AI Engineer learning roadmap.

## About

This project combines the Python fundamentals I learned during Week 1 into one practical application.

The system allows users to add students, view student information, search for students, calculate averages, find the top student, view passed students, and display overall statistics.

## Features

- Add a new student
- View all registered students
- Search for a student by name
- Calculate a student's average marks
- Find the top-performing student
- Display students who passed
- Display student statistics
- Interactive command-line menu
- Modular code using `utils.py`
